# 树状聊天系统 - 需求分析与系统设计

## 1. 项目概述

树状聊天系统是一种新型的聊天交互模式，通过树状结构组织对话，使用户能够在之前的任何时间节点上发起新的对话分支，从而实现上下文的有效管理和复用。该系统旨在解决传统线性聊天中上下文过长、信息混乱的问题，同时提供更灵活的对话管理能力。

## 3. 系统设计

### 3.1 架构设计

#### 3.1.1 系统架构

采用前后端分离架构：

- **前端**：React + TypeScript + Tailwind CSS
- **后端**：Node.js + Express + MongoDB
- **AI服务**：集成OpenAI API或其他LLM服务

#### 3.1.2 模块划分

| 模块名称 | 职责 | 技术栈 |
|----------|------|--------|
| 前端UI | 提供用户界面，处理用户交互 | React, TypeScript, Tailwind CSS |
| 前端状态管理 | 管理应用状态，包括对话树、当前分支等 | Redux Toolkit |
| 后端API | 提供RESTful API接口 | Express, Node.js |
| 数据存储 | 存储对话树和用户数据 | MongoDB |
| AI集成 | 与AI服务交互，处理上下文管理 | OpenAI API |
| 认证服务 | 处理用户认证和授权 | JWT |

### 3.4 前端设计

#### 3.4.1 页面结构

1. **登录/注册页面**：用户认证入口
2. **对话列表页面**：展示用户的所有对话树
3. **对话详情页面**：
   - 左侧：对话树导航面板
   - 右侧：消息内容展示区
   - 底部：消息输入框

#### 3.4.2 核心组件

| 组件名称 | 功能描述 | 技术实现 |
|----------|----------|----------|
| ConversationList | 展示对话列表 | React Component |
| TreeNavigator | 展示对话树结构，支持分支导航 | React Component + D3.js |
| MessageList | 展示消息内容 | React Component |
| MessageInput | 消息输入和发送 | React Component |
| BranchCreator | 创建新分支 | React Component |
| ContextManager | 管理上下文逻辑 | React Hook |

#### 3.4.3 交互流程

1. **创建对话**：用户点击"新建对话"按钮，创建一个新的对话树
2. **发送消息**：用户在输入框中输入消息，点击发送，系统将消息添加到当前分支
3. **创建分支**：用户在任意消息上点击"创建分支"，输入新消息，系统创建新的分支
4. **切换分支**：用户在树导航面板中点击不同分支，切换到对应分支的消息流
5. **编辑消息**：用户点击消息旁边的编辑按钮，修改消息内容
6. **删除消息**：用户点击消息旁边的删除按钮，删除消息及其子分支

### 3.5 后端设计

#### 3.5.1 核心服务

| 服务名称 | 职责 | 技术实现 |
|----------|------|----------|
| AuthService | 处理用户认证和授权 | JWT, bcrypt |
| ConversationService | 管理对话树的CRUD操作 | MongoDB |
| MessageService | 管理消息节点的CRUD操作 | MongoDB |
| AIService | 与AI服务交互，处理上下文管理 | OpenAI API |
| ContextService | 智能提取和管理上下文 | 自定义算法 |

#### 3.5.2 上下文管理策略

1. **分支隔离**：每个分支的上下文独立管理
2. **上下文压缩**：当上下文过长时，自动提取关键信息
3. **相关度分析**：基于消息内容分析上下文相关性
4. **历史参考**：在需要时参考历史消息，但不传递完整历史

### 3.6 数据库设计

#### 3.6.1 MongoDB集合

1. **users**：存储用户信息
2. **conversations**：存储对话树信息
3. **messages**：存储消息节点信息

#### 3.6.2 索引设计

| 集合 | 索引 | 用途 |
|------|------|------|
| users | email (unique) | 加速用户登录 |
| conversations | userId | 加速获取用户的对话列表 |
| messages | conversationId, parentId | 加速构建对话树 |
